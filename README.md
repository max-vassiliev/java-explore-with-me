# ExploreWithMe

ExploreWithMe — сервис для поиска событий. Пользователи могут находить и создавать мероприятия и собирать компании для участия в них.

## Технологии

* Java 
* Spring Boot
* REST API
* Сборка: Maven
* База данных: PostgreSQL
* Работа с базой данных: Spring Data JPA, Hibernate
* Микросервисная архитектура, взаимодействие между сервисами через WebClient
* Тестирование: Postman
* Docker

## Задачи по проекту

Проект реализован в рамках курса по Java-разработке. Это дипломный проект, в ходе которого отрабатывались все знания, полученные на курсе. При работе над проектом реализованы следующие задачи:

* Разделение API по типу доступа: публичный, для авторизованных пользователей и для администраторов
* Разделение проекта на два микросервиса: основной (`main-svc`) и сервис статистики (`stats-svc`); настройка взаимодействия между сервисами через WebClient
* Построение CRUD-операций и логики приложения согласно ТЗ
* Написание собственной функциональности без готового ТЗ — рейтинг событий
* Написание тестов на Postman для тестирования собственной функциональности
* Финальное закрепление ключевых тем курса

Проект создан за 6 недель и прошел ревью у профессиональных разработчиков.
